# 검수 기준

## 자동 검사

`npm test`는 실제 SDK의 직렬화·파싱과 저장소 동작을 검사합니다. 실제 배포 SQL 마이그레이션을 PGlite Postgres 엔진에 적용해 중복·공유 한도·revision·설문 중복·만료·트랜잭션 롤백을 확인하며, 독립된 Lua 기준 구현과 결과를 비교합니다. PGlite는 단일 프로세스이므로 여러 실제 DB 연결의 잠금 검수를 대신하지 않습니다. 자동 검사 성공을 유료 API나 이메일 실발송 성공으로 간주하지 않습니다.

주요 대상은 세션 서명, 이력 위·변조, 요청 형식·크기, 공유 한도·중복 처리, 안전 상태 전환, 현재 응급 상황 우선, 질문 거부, 구조화 출력·출력 검수, 중단·시간 초과, 인증·잔액·rate limit 구분, 설문 별도 동의·Netlify Forms 전용 필드·불확실한 접수의 재전송 차단입니다.

## 화면 검사

- 360px·390px 휴대폰, 768px 태블릿, 1440px 데스크톱에서 가로 넘침과 입력창 위치 확인
- 125개 감정·별칭·분류·직접 입력·미정, 여섯 강도 선택, 선택 버전과 후속 요청 일치
- 일기·도움·개인정보·설문 열기와 닫기, 키보드 포커스
- 설문 점수·자유 의견·선택 동의·보관 고지, 새 대화 초기화
- 페이지 이탈 후 뒤로가기에서 이전 입력·대화 초기화
- 연결 실패·시간 초과 시 입력 유지, 만료·상태 오류를 알리되 화면을 자동 삭제하지 않음
- 한글 조합 중 Enter로 조기 전송되지 않는지 실제 기기 확인

## 배포 후 연결 검사

최종 HTTPS 주소에서 페이지, 보안 헤더, 세션 쿠키, Origin 검증을 확인합니다. 운영자가 비밀 설정을 입력한 뒤 합성 대화 다중 턴·질문 거부·요약·안전 분기를 실제 API로 확인하고, 별도 합성 설문 1건의 수신까지 확인합니다. 검수용 입력에 실명·연락처·실제 상담 내용을 사용하지 않습니다.

실제 기기·계정·메일함 검수가 끝나지 않은 항목은 완료로 표시하지 않습니다. 납품 시점 실행 결과는 함께 제공하는 검수 기록을 확인하세요.

짧은 대화와 스트림 회귀는 `tests/short-chat.test.ts`에 있습니다. mock·SDK 전송 테스트와 실제 API 품질·지연 측정은 따로 기록합니다. 배포 전후 같은 합성 입력 3건의 네트워크 수신 시간, 별도 브라우저 performance mark의 실제 첫 표시, 기록 초안 생성과 명시적 마무리를 구분합니다. 소표본 분위수는 운영 p95 보장값이 아닙니다.
