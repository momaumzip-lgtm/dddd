## 데이터와 동의

대화·일기는 현재 화면 메모리에만 유지합니다. 새 대화·새로고침·페이지 이탈 때 초기화하며 앱 DB와 브라우저 영구 저장소에 원문을 기록하지 않습니다. 브라우저 자체·외부 AI·호스팅·이메일 서비스의 처리와 보존은 별도입니다.

익명 세션 쿠키는 최대 2시간 유지합니다. Netlify DB에는 서명 상태의 revision, 중복 방지 식별자, 카운터 등 기술 정보만 최대 25시간의 유효기간으로 관리하며 대화 원문을 저장하지 않습니다. 여러 서버에서 동시에 요청해도 공유 한도와 중복 방지는 Postgres 행 잠금·트랜잭션으로 처리됩니다. 만료값은 다음 요청 때 정리합니다. 호스팅 DB 백업에는 별도 보관 기간(현재 무료 플랜 예약 백업 3일, 게시 시 마지막 배포 백업)이 적용됩니다.

대화 전 안내 확인은 개인정보 처리 동의를 대신하지 않습니다. 설문은 별도의 선택 동의를 받아 점수·자유 의견만 이메일로 보냅니다. 필요한 별도 동의와 외부 처리 고지는 실제 운영 조건에 맞춰 확인해야 합니다.

## 장애 대응

- 인증·모델·잔액 부족 오류: OpenAI 계정 설정을 확인합니다. 키를 로그·스크린샷·이슈에 붙여 넣지 않습니다.
- rate limit·외부 장애·시간 초과: 입력은 유지됩니다. 통신 오류에서 자동 유료 재시도는 하지 않으며 이용자가 명시적으로 다시 요청합니다.
- 대화 만료·상태 불일치: 새 대화로 전환합니다. 이미 외부로 전송된 내용은 새 대화 버튼으로 소급 삭제되지 않습니다.
- DB 장애: 한도 확인을 우회하지 않고 요청을 차단합니다.
- 이메일 접수 불확실: 같은 본문·같은 중복 방지 키로 접수를 다시 확인합니다. 새 응답으로 자동 재전송하지 않습니다.

## 변경 및 롤백

코드 변경은 `main`에 반영하면 Netlify가 새 배포를 실행합니다. 배포 전 `npm run check`를 통과시키고 API·설문에 영향을 주는 변경은 합성 입력으로 실제 연결을 확인합니다. 문제가 생기면 Netlify Deploys에서 직전 정상 배포를 다시 게시합니다.

`SESSION_SECRET`을 바꾸면 기존 세션이 무효화됩니다. OpenAI·Resend 키는 새 키 등록, 재배포, 연결 검수 후 이전 키를 폐기합니다. Netlify DB 연결 값은 플랫폼이 관리합니다. 키 교체나 모델 변경 때 환경변수만 바꾸고 배포를 생략하지 않습니다.

## 운영자가 확정할 사항

외부 AI·호스팅·메일의 실제 데이터 처리·보존 조건과 로그 설정, 설문 발송 계정·수신 주소, 실제 모바일 기기 한글 입력·키보드 동작을 확인해야 합니다. 화면·합성 검사 통과는 임상적 안전성이나 치료 효과를 입증하지 않습니다.
